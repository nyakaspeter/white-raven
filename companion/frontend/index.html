App Sync server

The companion downloads and hosts the latest unrooted release on your local network.

Warning: App Sync removes all other user-installed widgets from the TV.

Choose your TV series:

E series · 2012
  1. Open Smart Hub, press the red A button, and sign in as develop. The usual password is 000000. If the account does not exist, create a Smart Hub account named develop and choose your own 6–12 digit password.
  2. Open Tools → Settings → Development → Setting Server IP.
  3. Enter — as four number groups in Setting Server IP.
  4. Select User Application Synchronization and wait for it to finish.
F series · 2013
  1. Press Menu → Smart Features → Samsung Account → Log In.
  2. Use username develop and password sso1029dev!, including the exclamation mark. If the password field is disabled, select it or continue without editing it.
  3. Open Smart Hub → More Apps → Options → IP Setting.
  4. Enter —, then return to Options and choose Start App Sync.
H series · 2014
  1. Press Menu → Smart Hub → Samsung Account → Log In.
  2. Enter develop and normally leave the password blank. If your firmware requires a password, try 000000; some versions accept any value.
  3. Open Smart Hub, highlight any installed app, then hold the remote's Enter/OK button until a menu appears.
  4. Select IP Setting and enter —.
  5. Hold Enter/OK on an app again and select Start User App Sync.

After synchronization: exit Smart Hub completely and reopen it. White Raven may appear at the end of the app list or under More Apps. If the TV cannot connect, check the companion device's firewall and confirm that nothing else is using TCP port 80.

SSH installation

Install the latest release directly over SSH. You can include the TV-local server or use the rootless widget with a server elsewhere on your network.
